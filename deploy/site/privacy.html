Kolf

Privacy

Kolf has no accounts and sends no usage data.

While you play online

The kolf.pro server keeps these in memory only while your lobby is open, and forgets them when it closes:

  • the names and colours you pick for your players
  • the course and the state of the match
  • your IP address, to limit how many connections and wrong join codes come from one place

Logs

The server records events like a lobby opening or a match finishing, with random IDs, how long the match took, and how many played. Names, join codes, and IP addresses are not logged. Logs are deleted after about 7 days.

The web server in front of kolf.pro keeps standard access logs, which include IP addresses, for up to 7 days to keep the service running and secure.
